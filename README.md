# Lingua Bridge — Prüfen & Aufnehmen

Werkzeug zur muttersprachlichen Prüfung von Somali-Wortdaten.
1.323 Einträge in Deutsch, Englisch, Af-Maxaa (Nord/Somaliland) und Af-Maay (Süd).

## Was man tun kann

- Wörter in **beiden somalischen Varietäten** ändern und verbessern
- **Sprachaufnahme** je Varietät — beliebig oft neu aufnehmen
- Aufnahmen als Datei herunterladen
- Als richtig, falsch oder unklar bewerten
- Korrekturen sichern und weitergeben

## Wichtig

Alles bleibt **im eigenen Browser**. Nichts wird hochgeladen.
Zum Weitergeben den Knopf **Sichern** benutzen und die Datei verschicken.
